# Electron Calculator 🧮  

A simple and lightweight desktop calculator built using **Electron.js**.  

## Features  
- **Basic Arithmetic Operations**: Supports addition, subtraction, multiplication, and division.  
- **User-Friendly Interface**: Minimalistic design for easy calculations.  
- **Lightweight**: Runs smoothly without consuming much system resources.  

## Installation  
1. Download the latest release from the [GitHub Releases](YOUR_GITHUB_RELEASE_LINK_HERE).  
2. Extract the ZIP file and open the `MyCalculator.exe` file.  
3. Start performing calculations!  

## Technologies Used  
- **Electron.js**  
- **HTML, CSS, JavaScript**
